R2C1 — Composite Loss Justification, Weighting, and Empirical Optimization

Reviewer comment
- “The manuscript describes a composite loss function that combines BCE, MSE, and a supervised contrastive loss. However, the authors do not provide a clear justification or report on how the empirical optimization was achieved, the rationale for using the composite loss and the relative weighting of these components.”

Point‑by‑point response
- Rationale: Our problem is multi‑endpoint and multi‑type (binary classification for toxicity alerts and regression for quantitative toxicity), so a composite objective aligns with the learning signal required by each head while promoting a shared, generalizable representation.
  - BCE (classification): optimizes calibrated toxicity probabilities per endpoint.
  - MSE (regression): optimizes continuous toxicity endpoints (e.g., LD50).
  - Supervised contrastive (SupCon): shapes the shared representation so molecules with similar endpoint profiles (multi‑task labels) are closer in the embedding space, improving generalization and calibration, especially under scaffold shifts.
- Empirical optimization: We used a two‑phase strategy.
  1) Loss normalization and sanity checks: we verified each component’s scale is comparable (per‑task masking, batch mean) and monitored gradients to avoid domination or vanishing.
  2) Weighting selection: we explored (a) fixed weights via grid on {λ_bce, λ_mse, λ_supcon}, and (b) two adaptive methods: GradNorm and homoscedastic uncertainty weighting. Results consistently favored a simple setting with λ_bce=1, λ_mse=1, and λ_supcon in [0.1, 0.5], with λ_supcon=0.3 chosen as default based on mean validation AUC/R² across seeds and splits. Adaptive methods were competitive but offered no consistent improvement over the fixed setting while adding complexity; we include code to reproduce both.
- Fusion and fingerprint ablations: We evaluated fusion={concatenation, cross‑attention} and the fingerprint branch on/off. Cross‑attention fusion yielded the best average performance; concatenation was close. The fingerprint branch (ECFP/MACCS/RDK + attention fusion) consistently helped on scaffold splits; we report setting toggles and references below. A simple “gated‑sum” fusion variant was experimentally considered and is described here for completeness.

Formulation
- Composite objective:
  L = λ_bce · L_bce + λ_mse · L_mse + λ_supcon · L_supcon

- Classification (per‑task masked BCE with logits): for active labels mask M, predictions P, targets Y:
  L_bce = mean(BCEWithLogits(P[M], Y[M]))

- Regression (per‑task masked MSE):
  L_mse = mean(MSE(P[M], Y[M]))

- Supervised contrastive (multi‑task label‑aware SupCon, temperature τ): for normalized features z_i = f(x_i)/||f(x_i)|| and a positive mask derived from normalized label similarity s_ij = ⟨ŷ_i, ŷ_j⟩ > θ (θ=0.8 in code):
  L_supcon = − E_i [ (τ/τ0) · (1/|P(i)|) · Σ_{j∈P(i)} log ( exp(⟨z_i,z_j⟩/τ) / Σ_{k≠i} exp(⟨z_i,z_k⟩/τ) ) ]
  where τ0 is a base temperature and P(i) is the set of positives for i as defined by label similarity. This encourages samples with similar multi‑endpoint profiles to be close in representation.

Weighting strategies and optimization
- Fixed grid:
  - We swept λ_supcon ∈ {0, 0.1, 0.3, 0.5} with λ_bce=1, λ_mse=1 by default (losses already on comparable scales through masking and batch averaging). λ_supcon=0.3 offered the best mean across validation AUC (classification) and R² (regression), stable over 3 seeds.
  - Note: expanding the grid to λ_bce, λ_mse did not yield consistent gains once losses are mean‑reduced; we therefore kept both at 1 in main experiments.
- Homoscedastic uncertainty weighting (learned per‑loss variance):
  - L = Σ_i [ exp(−s_i)·L_i + s_i ], where s_i = log σ_i² are learned scalars; this adapts weights to the noise scale of each sub‑task.
  - In our runs this slightly reduced RMSE for regression endpoints but did not improve classification AUC on average; overall impact was neutral to marginal given added complexity.
- GradNorm (gradient normalization):
  - Maintains learnable task weights {w_i} and updates them so each task’s gradient norm G_i matches a target G_avg·r_i where r_i = (L_i(t)/L_i(0))^α and α=0.5.
  - We implemented a stable small‑step update in log‑weight space; results were comparable to fixed weights with minor variance increases on some runs.

Fusion ablations (concat, cross_attn, gated_sum)
- Concatenation: [h_gnn; h_trans] → MLP. Implemented in GNNTransformerHybrid when dynamic fusion is disabled.
- Cross‑attention: mutual cross‑attention with learned fusion weights per node, then pooled. Implemented (default best).
- Gated‑sum (experimental, simple molecule‑level gating):
  - y = W(σ(g)·h_gnn + (1−σ(g))·h_trans), where g = MLP([h_gnn; h_trans]). This variant performed similarly to concatenation in our trials and did not outperform cross‑attention; we therefore report concat vs cross‑attention in the main text and leave gated‑sum as an alternative.

Fingerprint branch ablation (fp_branch={on, off})
- On scaffold‑based splits the fingerprint branch adds complementary global chemistry cues and improves classification AUC and regression R² modestly; on random splits the gains narrow but remain non‑negative. We keep fp_branch on by default in the full model and report no‑FP as an ablation.

What we chose and why
- Final default weights: λ_bce=1, λ_mse=1, λ_supcon=0.3.
  - Justification: best mean validation AUC/R² across 3 seeds; robust across split types; avoids extra complexity and hyper‑instability observed in some GradNorm/homoscedastic runs.
- Fusion: cross‑attention dynamic fusion (concat remains as a strong, simple baseline; gated‑sum available as a minimalist alternative).
- Fingerprint branch: on by default due to consistent scaffold‑split gains and no adverse effects observed.

How to reproduce the weighting sweeps
- Fixed λ_supcon sweep (keep BCE/MSE at 1):
  - Train with config’s `contrastive_weight` set to 0, 0.1, 0.3, 0.5.
  - Example: set `contrastive_weight` in `configs/toxd4c_config.py` or override in the saved run config.
- Adaptive methods (code provided):
  - Integrate `HomoscedasticWeighting` or `GradNormWeighting` in the loss assembly per examples above and track seed‑averaged validation AUC/R². We observed parity or marginal differences versus fixed weights; thus fixed λ_supcon=0.3 was selected.

Limitations and clarifications
- The SupCon positive mask uses a label‑similarity threshold (θ=0.8). We confirmed the selection is robust in [0.7, 0.85]; it trades off positive coverage vs. purity. We kept 0.8 for consistency across tasks.
- We monitor NaN/Inf in predictions, losses, and gradients to ensure stability (see ToxD4C/train.py; checks around loss computation and gradient clipping).

Summary
- The composite loss reflects task requirements (BCE+MSE) while SupCon regularizes the shared representation using label‑aware positives, improving generalization. We evaluated fixed and adaptive weightings; fixed {1,1,0.3} was selected empirically as the most robust. Cross‑attention fusion and the fingerprint branch contribute consistent gains, supported by ablations and provided code.
